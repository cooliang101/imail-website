Local-first. Open source.

多个邮箱，
一处从容处理。

iMail 是一款本地优先的邮件客户端。把收件、搜索、撰写与日常整理放在同一个界面，让你专注于邮件本身。

查看项目与使用指南 ↗了解数据如何使用

Windows 桌面 · Docker 自托管 · MIT 开源 · 当前处于内部测试阶段

01 / 邮箱汇集

熟悉的邮箱，一起管理

支持 Gmail、Outlook、QQ 邮箱、Yahoo、iCloud，以及其他 IMAP/SMTP 邮箱。使用 OAuth 或服务商支持的应用专用密码接入。

02 / 日常处理

从阅读到整理

阅读与发送邮件、管理附件和草稿、搜索历史邮件、设置已读与星标，并通过文件夹、联系人和邮件规则整理收件箱。

03 / 部署选择

数据保存在你选择的环境

桌面本地模式在设备上保存数据；Docker 和远程模式使用你选择的自托管服务。不同实例不会自动合并邮件数据。

Your mail, your context.

再连接邮箱。

连接 Google 账户时，iMail 请求账户身份与邮件访问权限，以提供邮箱同步、阅读、发送和整理功能。凭据加密保存；邮件缓存与备份需要由设备或服务器所有者妥善保护。

云端翻译和外部 API / MCP 为可选功能，启用后会涉及向你选择的服务传递数据。完整说明请阅读隐私政策。
