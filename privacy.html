隐私政策

更新日期：2026 年 9 月 10 日 · 应用名称：Cooliang iMail（iMail）

iMail 是由 Cooliang 维护的独立开源邮件客户端。本政策说明官方项目如何访问、使用、存储与共享数据。自托管服务的运营者还应说明其服务器、日志和备份实践。

1. 访问的数据及用途

当你添加邮箱时，iMail 处理邮箱地址、显示名称、连接设置和授权凭据，并按你的使用情况同步邮件头、发件人与收件人、主题、正文、附件、文件夹及已读、星标等状态。联系人可从邮件参与人信息生成，用于展示与地址建议。

这些数据用于提供邮件阅读、发送、搜索、附件处理、草稿、规则与邮箱整理功能。删除、移动和规则操作可能同步到原始邮箱服务器。

2. Google 账户与 Gmail 权限

连接 Gmail 时，iMail 使用 Google OAuth 获取身份信息和访问令牌。请求的权限包括 openid、email、profile，以及 https://mail.google.com/ 邮件权限；邮件权限用于通过 IMAP/SMTP 同步、阅读、发送、移动和删除邮件。OAuth 方式不会要求你向 iMail 提供 Google 登录密码。

Google 用户数据仅用于上述用户可见的邮件功能，不用于广告投放、出售给数据经纪商、信用评估，或训练通用人工智能模型。对通过 Google API 获得的信息的使用及向其他应用的转移，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

3. 数据保存与保护

桌面本地模式在你的设备上保存邮件数据。Docker 服务与桌面远程模式将数据保存在你选择的 iMail 服务器及其数据目录中，服务器管理员可能访问该环境中的数据。项目维护者不会因为你使用自托管软件而自动收到你的邮箱数据。

邮箱密码、应用专用密码和 OAuth Token 使用实例密钥加密保存。邮件正文、附件缓存和数据库备份并不因此自动获得整库加密；请使用设备加密、访问控制和安全备份保护它们。密钥与数据目录需一并妥善保护。网络连接应使用 TLS，远程服务应通过 HTTPS 访问。

4. 数据传递与可选功能

  • 邮箱操作会与对应邮箱服务商通信；发送邮件会把内容传递给你指定的收件人及相关邮件服务。
  • 开启云端翻译并同意相应提示后，待翻译文本会发送到你选择的翻译提供商。本地翻译与云端翻译具有不同的数据边界。
  • API Gateway 和 MCP 默认关闭。你主动启用并向外部工具签发授权后，该工具可在授权范围内读取或操作邮件。请只向可信服务提供授权。
  • 查看远程邮件图片或获取联系人域名 Logo 时，相关网络请求可能向资源提供方暴露 IP 地址、请求时间或域名信息；是否发生取决于你使用的功能和设置。
  • 你主动提交支持邮件、问题报告或日志时，维护者会处理你提供的信息来协助解决问题。请勿提交邮箱凭据或未经脱敏的私人邮件。

维护者不出售或出租你的 Google 用户数据，也不会在没有你主动提供或授权的情况下为日常支持读取你的私人邮件。

5. 保留、删除与撤销授权

已同步的数据在对应设备或服务器中保存，直至按应用行为清理或由你删除。你可以移除邮箱账户，或在“隐私与数据”中清理当前用户的数据。独立备份、导出文件、已下载附件和服务器日志需要由其持有者另外管理。卸载应用不一定删除数据目录。

你可以在 Google 账户的第三方连接中撤销 iMail 的授权。撤销会阻止后续访问，但不会自动删除此前保存在设备或自托管服务器中的缓存。若使用他人运营的服务，请联系该运营者处理其保留的数据。

6. 本网站

本网站是静态的产品与政策说明页面，不要求登录邮箱，不收集 OAuth Token，也不包含邮件处理功能。本页面未嵌入广告、第三方统计脚本或主动设置 Cookie；托管与网络服务提供方仍可能为运行和安全目的处理 IP 地址、访问时间等请求信息。

7. 联系与更新

联系维护者：cooliang101@gmail.com。如对数据使用或删除有疑问，请说明你使用的是本地模式还是自托管服务，勿附带密码或 Token。政策更新会在本页注明日期；涉及新增数据用途时，应在相应功能中向用户说明并在需要时重新征得同意。
